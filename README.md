# Kush Singh – Content Writer Portfolio

React + TypeScript + Vite.

## Run
```bash
npm install
npm run dev        # development
npm run build      # type-check + production build (dist/)
npm run preview    # preview the build
```

## Structure
- `src/data/projects.ts` – 16 typed writing samples (edit/add projects here)
- `src/data/content.ts` – nav, services, process, FAQ, contact details
- `src/components/` – Nav, Hero, About, Work (filter chips + cards), ProjectDialog, Services, Process, Faq, Contact
- `src/styles.css` – original styles (light/dark theme preserved)
